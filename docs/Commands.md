# Commands

EzTax provides several commands for players and administrators. Below is a list of available commands, their usage, and descriptions.

| Command                | Usage / Arguments                | Description                                 | Permission                |
|------------------------|----------------------------------|---------------------------------------------|---------------------------|
| /tax check             |                                 | View your current tax and fines             | eztax.command.check       |
| /tax pay               |                                 | Pay your outstanding taxes                  | eztax.command.paytax      |
| /tax payfine           |                                 | Pay your outstanding fines                  | eztax.command.payfine     |
| /tax show              |                                 | Show detailed tax information               | eztax.command.showtax     |
| /tax fines             |                                 | Show detailed fines information             | eztax.command.showfines   |
| /tax stats             |                                 | View tax statistics                         | eztax.command.stats       |
| /tax reload            |                                 | Reload the plugin configuration             | eztax.command.reload      |
| /tax sinks             |                                 | View economic sinks                         | eztax.command.sinks       |
| /tax runtaxpayment     |                                 | Force a tax payment run                     | eztax.command.runtaxpayment |
| /tax runwealthtax      |                                 | Force a wealth tax run                      | eztax.command.runwealthtax |

> **Tip:** Use `/tax help` in-game for a list of commands and descriptions.
