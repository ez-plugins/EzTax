# Tax Types

EzTax supports four configurable tax types. Each can be enabled and tuned independently in `config.yml`.

| Type | Description |
|------|-------------|
| [Transaction Tax](transaction-tax.md) | Applied as a percentage when a player sends money |
| [Wealth Tax](wealth-tax.md) | Periodic tax on a player's total balance |
| [Inactivity Fee](inactivity-fee.md) | Charged to players who have not been online recently |
| [Death Fee](death-tax.md) | Deducted from a player's balance on death |
