# EzTax Plugin

EzTax is a professional, configurable tax and fine management plugin for Minecraft servers. It automates tax collection, fines, and economic sinks, supporting multiple languages and advanced configuration.

## Features
- Automated tax collection (wealth, income, death fees)
- Fine management and payment system
- Configurable tax intervals and rates
- Multi-language support
- Vault economy integration
- Command-based management for admins and players
- Metrics and statistics tracking

## Installation
1. Download the EzTax plugin JAR and place it in your server's `plugins` folder.
2. Restart or reload your server.
3. Configure the plugin using `config.yml` and `plugin.yml` in the `resources` folder.

## Usage
- Use `/tax` and related commands to interact with the plugin.
- See [docs/Commands.md](docs/Commands.md) for a full command list.
- See [docs/Permissions.md](docs/Permissions.md) for permission nodes.

## Configuration
- Main configuration: `src/main/resources/config.yml`
- Messages: `src/main/resources/messages/`
- Plugin metadata: `src/main/resources/plugin.yml`
